          How to Use

          Install App

          • Use Add to Home Screen / Install App to use it as a PWA (faster, own icon, device app lock).
          • Tapping install button after open playstore then app automatically installed in your mobile

          Reminders

          • Reminders page → ＋ Add New Reminder → Title, Start date, End date → Save.
          • Edit with ✏️, delete with 🗑️. Today and tomorrow due reminders show on Home.

          Notes

          • Notes page → ＋ Add New Note → write text, optionally attach a file or tick table format → Save.
          • Saved date and time are added automatically and shown with each note, also on Home.

          Budget Tracker

          • Add a budget with a total amount and days. The app shows the cost per day.
          • Add expenses to track spending. A daily reminder shows your spend limit.

          Checklist

          • Create a checklist and set it Open or Closed. Open checklists show on Home.

          Priority Queue

          • Pick a date, type an item, click Add. Tick the box when done.
          • Unchecked items move to the next day automatically.

          Progress Tracker

          • Add a progress title and date, then add steps (text or a file) under it.
          • Home shows each progress title with its number of steps. Tap it to open the page.

          Trash Bin

          • Deleted items go to the Trash Bin. Click ♻️ to restore them.

          Settings

          • Edit Name, Dark Mode and Notification Settings are inside ⚙️ Settings.
          • Click the profile picture to change it.
          • Notifications can be turned on or off for each feature. Allow notifications for this site in your browser.

          Import & Export (Backup)

          • Open ⚙️ Settings and click the 💾 storage button.
          • Export Data: downloads one backup file with all your data (reminders, notes, budgets, checklists, priority queue, progress, trash, files) and settings (name, photo, dark mode, notification choices).
          • Import Data: choose a backup file. All current data and settings are replaced by the backup and the app reloads.
          • Export regularly and before clearing browser data or changing your device. Use Import on the new device to restore everything.

          Offline Mode

          • Download the source code, extract it and open index.html without internet. Notifications will not work offline.
